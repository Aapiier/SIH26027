# 18_EDGE_CASES_FAILURES_AND_RECOVERY.md — Edge Cases, Failure Modes & Recovery Matrix

## SIH26027: AI-Powered Automatic Block Planning to Maximize Asset Availability for Train Operations on Indian Railways

---

## 1. Safety Failure Policy

> [!CAUTION]
> **Fundamental Safety Invariant:** RailSync AI must **fail safely**. Under no circumstances should an unexpected error, missing dataset, corrupted ML model, or solver timeout produce an invalid, unverified, or dangerous track possession schedule.

---

| **EC-008** | Orphan Asset ID Reference | `asset_id` not in `assets` table | Quarantine row; log missing asset ID in Data Health report. | "Task rejected: Asset AST-999 not found in network asset database." | Add missing asset to registry or reassign to valid asset. | `TC-EDG-008` |
| **EC-009** | Duplicate Task Ingested in Sync | SHA-256 hash or `(source, record_id)` match | Idempotent upsert; update timestamp without duplicating queue entry. | "Duplicate task detected: Record updated without duplicate creation." | None required (automated idempotent handling). | `TC-EDG-009` |
| **EC-010** | Stale Source Timetable Feed | Timetable date $< t_{\text{horizon\_start}}$ | Block solver execution; flag `STALE_TIMETABLE_ERROR`. | "Cannot optimize: Timetable is out of date. Please sync latest COA." | Trigger fresh COA sync before running optimizer. | `TC-EDG-010` |
| **EC-011** | ML Model Binary Missing or Corrupt | `FileNotFoundError` or unpickling failure | Log alert; seamlessly fall back to deterministic safety rule score. | "Notice: ML priority engine inactive. | **EC-012** | ML Model Emits NaN / Infinite Score | `np.isnan(score)` or `score < 0` | Catch exception; assign default score based on defect severity enum. | "Notice: Anomaly in ML score calculation. Defaulted to severity baseline." | Log feature vector for model debugging. | `TC-EDG-012` |
| **EC-013** | No Feasible Window for Critical Task | Candidate window search returns $\emptyset$ | Leave task unscheduled; trigger `CRITICAL_UNSCHEDULED_ALERT`. | "CRITICAL ALERT: Emergency task TSK-01 cannot fit into train timetable." | Alert Chief Controller immediately; propose train regulation / reroute. | `TC-EDG-013` |
| **EC-014** | Window Shorter Than Task Duration | $\text{net\_duration}(w) < D_t + 30\text{m}$ | Task remains unscheduled with diagnostic `DURATION_EXCEEDS_GAP`. | "Task unscheduled: Required 180 min exceeds maximum available gap (120 min)." | Suggest task splitting (e.g. 2 x 90 min) or wider traffic block. | `TC-EDG-014` |
| **EC-015** | Heavy Machinery Resource Bottleneck | 3 tasks demand single Tamping Machine | Solver allocates machine to highest priority; defers lower priority. | "Tamping Machine #01 fully booked. | **EC-016** | Specialized Crew Double-Booking | Crew required by 2 concurrent blocks | Hard Constraint #6 prevents concurrent assignment. | "S&T Gang #3 allocated to higher-priority task. Second task deferred." | Re-allocate gang or shift window. | `TC-EDG-016` |
| **EC-017** | Incompatible Tasks Attempted to Bundle | Track lifting + relay splicing in bundle | Bundling engine compatibility matrix rejects bundle formation. | "Bundling prevented: Track tamping is incompatible with signal splicing." | Tasks scheduled in separate non-overlapping windows. | `TC-EDG-017` |
| **EC-018** | Precedence Dependency Violation | Dependent task scheduled before parent | Hard Constraint #10 enforces strictly ordered interval sequence. | "Schedule ordered: Deep screening task strictly precedes tamping." | Handled mathematically by CP-SAT precedence constraints. | `TC-EDG-018` |
| **EC-019** | Electrical Power Cutoff Conflict | 25kV cutoff requested during electric train run | Hard Constraint #9 enforces power isolation non-overlap with electric trains. | "Power isolation window adjusted to avoid electric passenger train." | Solver schedules OHE cutoff in zero-electric-traffic shadow block. | `TC-EDG-019` |
| **EC-020** | CP-SAT Solver Timeout | Runtime exceeds configured limit (30s) | Solver returns best feasible solution found; labels status `FEASIBLE_SUBOPTIMAL`. | "Optimization completed (Time limit reached; feasible solution found)." | Increase solver time limit if closer optimality is desired. | `TC-EDG-020` |
| **EC-021** | CP-SAT Model Infeasible ($0$ solutions) | Hard constraints mathematically mutually exclusive | Return zero schedule; log infeasibility diagnostics; do not crash. | "Infeasible: Current traffic and resource bounds cannot satisfy hard rules." | Relax soft resource bounds or inspect conflicting constraints. | `TC-EDG-021` |
| **EC-022** | Independent Schedule Validator Failure | Post-solver checker detects buffer breach | Block schedule persistence; flag `REJECTED_BY_VALIDATOR`. | "CRITICAL ERROR: Generated schedule failed safety validation. Blocked." | Audit solver formulation; inspect candidate window generation. | `TC-EDG-022` |
| **EC-023** | Sudden Passenger Train Delay ($> 30\text{ min}$)| Delayed train intersects approved block | Mark block `STALE_NEEDS_REPLAN`; trigger localized re-optimization. | "Train #12951 delayed by 45 min. Impacted block flagged for replanning." | Execute targeted re-optimization on impacted corridor segment. | `TC-EDG-023` |
| **EC-024** | Sudden Emergency Defect Injected | Rail fracture reported during active day | Inject emergency task; recompute candidate gaps; replan affected sector. | "EMERGENCY: Rail fracture reported. | **EC-025** | Unscheduled Freight Surge | Extra freight paths inserted into COA | Reduce candidate window confidence; adjust soft freight penalty. | "Freight traffic surge detected: Shadow block confidence adjusted." | Solver balances freight delay vs maintenance urgency. | `TC-EDG-025` |
| **EC-026** | User Attempts Invalid Manual Override | Controller drags block into train movement | Real-time safety validator blocks override with conflict details. | "Override Rejected: Overlaps with Train #12002 at 02:15 UTC." | Controller must choose a safe non-conflicting time window. | `TC-EDG-026` |
| **EC-027** | Concurrent Override Collision | Two users modify same schedule block | Optimistic concurrency check via `version` column fails second request. | "Conflict: Schedule was modified by another user. | **EC-028** | Unauthorized Approval Attempt | Non-Chief Controller clicks "Approve Plan" | FastAPI HTTP 403 Forbidden exception raised. | "Access Denied: Only Chief Controllers may approve maintenance plans." | User must log in with authorized credentials. | `TC-EDG-028` |
| **EC-029** | CSV Export Formula Injection Attempt | Malicious text string in task description | Sanitizer prefixes single quote (`'`); neutralizes spreadsheet formula. | Export completes cleanly; formula characters escaped. | Handled automatically by `sanitize_csv_field` utility. | `TC-EDG-029` |
| **EC-030** | Database Connectivity Interruption | SQLite locked or Postgres connection timeout | Retry connection with exponential backoff (3 attempts); return 503. | "Service Temporarily Unavailable: Database connection retry in progress." | Check database server status; restart local backend daemon. | `TC-EDG-030` |
